## 技术实现

纯静态站点，无框架、无构建步骤、无外部依赖（字体走系统字体栈，不请求 CDN）。

```
index.html    页面结构与内联 SVG 插画
style.css     设计系统与响应式
script.js     交互增强（渐进式，禁用 JS 页面依然完整可读）
assets/       循环视频、视频封面、简历 PDF
```

## 特性

- 首屏全幅无缝循环视频 + 蒙版，`IntersectionObserver` 驱动滚动入场与数字滚动
- 视频在不支持 / 减弱动效 / 离屏 / 切换后台时自动暂停
- 完整响应式，`prefers-reduced-motion` 全量降级
- `@media print` 打印样式，浏览器直接 `Ctrl/⌘ + P` 可导出浅色 PDF
- 键盘可达，滚动区高亮，点击复制联系方式
