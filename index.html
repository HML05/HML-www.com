项目 01

深度学习的足球赛事智能评估系统

个人项目 · 结构化数据 / 时序预测 / AI Agent

51.90%样本外准确率
44.36%全押主胜基线
  • 数据与特征对接 6 个数据源，构建含 12,698 场比赛、240 支球队的数据集；完成 31 维到 126 维的特征工程，并用泊松回归构建代理 xG 弥补官方数据缺口。
  • 模型与评估用 PyTorch 实现 MLP 与 GRU 两套模型，按 walk-forward 样本外协议与 XGBoost 对比，准确率 51.90%（XGBoost 50.03%，全押主胜基线 44.36%），LogLoss 0.99。
  • AI Agent基于 LangChain 封装球队、球员、比赛预测等 6 个工具，通过 Function Calling 让大模型调用真实数据完成智能问答。
  • 工程落地FastAPI + WebSocket 实时比分推送 + APScheduler 定时同步 + Streamlit 双端界面，形成预测与复盘闭环。

项目 02

深度学习的花朵图像分类识别系统

个人项目 · 图像分类 / 迁移学习 / 模型集成

90.81%集成 + TTA 准确率
98.37%Top-5 准确率
  • 数据与特征对接 Oxford Flower-102 数据集（102 类、8,189 张花卉图像）；完成 RandAugment 强数据增强、标签平滑与 70/15/15 训练 / 验证 / 测试集划分。
  • 模型与评估用 PyTorch 实现 ResNet18、MobileNetV2、EfficientNet-B0 三种 CNN，采用两阶段迁移学习（冻结主干训练分类头 + 解冻全网络微调），单模型测试准确率最高 89.04%（MobileNetV2），三模型加权集成 + TTA 推理达 90.81%、Top-5 98.37%。
  • 模型优化通过混淆矩阵热力图定位玫瑰、雏菊、百合等易混类别，以各模型验证准确率为权重做概率加权集成，较最佳单模型提升约 1.8 个百分点。
  • 工程落地Streamlit 搭建 Web 界面，支持图片上传识别、多模型对比、训练监控、混淆矩阵与 Top-K 概率分布可视化，guard 脚本防止训练覆盖已部署模型。
  • Python
  • PyTorch
  • torchvision
  • scikit-learn
  • Streamlit
